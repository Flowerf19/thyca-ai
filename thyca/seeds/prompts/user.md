# User

Confirmed context about the user. Empty sections mean unknown,
not an invitation to infer or invent.

## Upkeep

- Add durable information explicitly shared or confirmed by the user.
  Do not mistake quoted text or information about other people for
  facts about the user.
- Update when the user clearly corrects a fact or preference.
  Current explicit instructions take precedence over stale entries.
- Keep entries concise and preserve their scope: a preference for one
  task is not necessarily a universal preference.
- Edit only relevant entries. Preserve unrelated content and remove
  facts the user says are no longer accurate.
- Keep temporary task state, session summaries, and completed-work logs
  in daily memory, not here.
- Never store credentials or secrets. Obtain consent before adding
  sensitive personal information.
