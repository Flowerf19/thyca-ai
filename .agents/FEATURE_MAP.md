## 2. Standard Verification Gates

- **Tier 1 (Deterministic Guardrails — 0 errors required):**
  ```bash
  bash scripts/checks/check-tier1.sh
  ```
  Runs `ruff check .`, `node --check` on all `.js`/`.mjs` files, architectural boundary + version sync checks, `scripts/checks/check-no-weakened-tests.sh`, `scripts/checks/check-comment-ban.sh`, and `git diff --check`.
- **Tier 2 (Full Test Suite & Verification Artifacts):**
  ```bash
  uv run pytest -q
  bash scripts/checks/check-artifacts.sh .agents/artifacts
  ```
- **Optional Live Provider Scenarios (explicit opt-in only):**
  ```bash
  THYCA_LIVE=1 uv run pytest -q -m live tests/test_live_memory_agent.py
  ```
