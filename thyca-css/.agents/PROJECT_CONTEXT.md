# Project context

Standalone static HTML/CSS reconstruction of the user-supplied Thyca reference image at `/tmp/pi-clipboard-455b982e-7ee0-41bb-aa9f-73c25edfa205.png` (1536×1024).

- No build system or dependency.
- No Thyca backend/API integration.
- `index.html` is the preview surface; `styles.css` owns all visual styling.
- Desktop reference is the source of truth; mobile is a responsive adaptation that drops the spiral and turns the sidebar into a compact top sheet.
